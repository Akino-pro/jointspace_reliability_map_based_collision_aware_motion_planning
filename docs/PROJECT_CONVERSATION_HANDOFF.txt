6. THEORY DISCUSSION: ENDPOINTS ON CONTINUOUS SSMS

Original question:
Both task positions have infinitely many redundant configurations. Which start
and goal configurations should GCS choose to minimize the motion cost?

Agreed distinctions:
- GCS does not require a single fixed goal configuration. A convex target set,
  or multiple point/convex targets connected to a common sink, can be modeled.
- A nonlinear SSM is generally nonconvex and cannot simply be treated as one
  ordinary convex GCS vertex without relaxation or approximation.
- With no obstacles and pure joint-space Euclidean length, free endpoint
  selection means minimizing distance between the two SSMs. A known start
  configuration reduces this to distance from that point to the goal SSM.
- With obstacles, endpoint and route selection are coupled. With nonconstant
  reliability weights, Euclidean-nearest endpoints need not minimize cost.
- Nearest-point projection onto a nonconvex SSM need not be unique.
- Solving to an SSM bounding box/convex hull, then projecting the endpoint onto
  the SSM, gives a candidate; it is not generally an exact optimal solution.

Concrete counterexample used in the conversation:
This is a planar geometric illustration, not a claim that an actual 3R SSM has
this exact shape. All space is obstacle-free and all cost weights equal 1.
  Goal curve S: x^2 + y^2 = 1.
  Convex target C: [-1,1]^2, exactly the curve's bounding box.
  Known start q0: (2, 0.5).
The shortest path to C ends at p=(1,0.5), length 1.
The nearest curve point to p is
  q_proj=(2/sqrt(5), 1/sqrt(5)) approximately (0.8944,0.4472).
The true nearest curve point to q0 is
  q_star=(4/sqrt(17), 1/sqrt(17)) approximately (0.9701,0.2425).
Costs:
  q0 -> p -> q_proj: about 1.1180.
  q0 -> q_proj directly: about 1.1068.
  q0 -> q_star directly: about 1.0616.
Thus even replanning directly to the projected configuration does not make that
configuration optimal. Nearest to p is different from nearest to q0.

7. CENTERS, EROSION, DILATION, AND POSSIBLE NOVELTY

The user proposed collapsing SSM shapes to physical/geometric centers, connecting
nearby centers, then recovering endpoints by outward growth.

Conclusions and conditions:
- A general curve's closest pair is not determined by its geometric centers.
- At smooth regular interior minimizers, the connecting segment must be normal
  to both curve tangents. A center line need not satisfy this condition.
- Ordinary erosion followed by dilation is a morphological opening, not in
  general an inverse operation that exactly restores the original shape.
- Isotropic equal-distance growth from a point yields a disk/ball, not an
  arbitrary ellipse. An arbitrary shape needs additional information.
- A medial-axis transform retains centers AND their radius function; it is
  related to exact reconstruction by unions of maximal balls.
- If two disjoint sets really are fixed-radius offsets of center sets,
    A = C_A (+) B_rA, B = C_B (+) B_rB,
  then under ordinary Euclidean distance:
    dist(A,B) = dist(C_A,C_B) - rA - rB.
  In that special setting, closest centers recover facing closest boundary
  points. Variable radii require comparing center distance minus BOTH radii;
  nearest centers alone are insufficient. Direction-dependent growth requires
  additional geometry as well.
- Obstacles generally destroy this simple straight-line construction. If the
  obstacle-free global shortest segment is itself collision-free, it remains
  optimal for pure length. This does not settle weighted-cost optimality.
- No novelty claim was established. The basic geometry and center/radius shape
  representation have substantial prior work. A useful SSM representation,
  error guarantee, or planning speedup might constitute a contribution, but
  requires a more systematic literature review and evidence.
- A generic planar-3R position SSM is a 1D curve in 3D joint space; classical
  interior medial-axis constructions for filled objects do not transfer to it
  automatically.

Role of epsilon and the computational tradeoff:
- The user initially proposed a threshold based on convex-hull boundary distance
  to the nearest SSM sample. Operationally this must specify how distances over
  the boundary are aggregated, e.g. a maximum, not just a single minimum.
- This is a geometric resolution parameter chosen before planning, not an error
  measured against an already known globally optimal path.
- Smaller epsilon is intended to create more, tighter local envelopes, improving
  goal configuration estimation while usually enlarging the FIRST GCS problem
  and increasing its runtime. The final problem still has one fixed goal q_hat.
- The user does NOT intend repeated GCS solves over an epsilon sweep until a
  minimum cost is discovered. Geometric subdivision happens before the first
  solve; the basic pipeline has TWO GCS solve stages.
- Geometric grouping/hull calculations have their own cost but do not require
  solving a GCS problem for every proposed split or every local hull.
- Finer envelopes are expected to reduce approximation error overall; strict
  monotonic decrease of final path cost for every epsilon change is not proved.
- Fixed sampling density places a limit on continuous-SSM accuracy. Smaller
  epsilon does not replace missing curve information.
- Boundary-only distance does NOT bound distances of all interior target points
  to the SSM. A densely sampled unit circle has a polygonal hull whose boundary
  approaches the samples, while its center remains distance 1 from the circle.
  GCS can select an interior point. This is a known limitation of the proposed
  boundary metric, not an agreed requirement to implement a complex certificate.
- A rigorous bound would control sup_{p in T_i} dist(p,S_i), with appropriate
  safe local SSM portions S_i and continuous coverage assumptions. Such proof is
  optional future work, not a prerequisite for testing the heuristic pipeline.

Convex hull facts discussed:
- One call with 300 points produces ONE hull of all 300 points, not 300 hulls.
- The hull conv{q_i} consists of all convex combinations of the supplied points.
  It is the unique smallest convex set containing those points in the chosen
  Euclidean angular chart.
- Multiple hulls require partitioning/grouping first, possibly with overlapping
  sliding windows. Group by continuous branch order, not arbitrary point order.
- A smaller point count per group alone does not prove a tighter approximation;
  spatial span, curvature, sampling density, and branch separation matter.
- A single convex envelope of an entire nonconvex SSM cannot shrink past its
  convex hull. Multiple local envelopes avoid some of that geometric looseness.
- Hulls of sampled curve points need not enclose the curve between samples.
  A chord does not enclose its circular arc. Simply sampling densely does not
  by itself give a rigorous outer-coverage guarantee.
- To claim coverage of a continuous SSM, construct certified local outer
  envelopes, or expand hulls using a justified interpolation/sampling error bound.
- An unexpanded sample hull can be lower dimensional. Adding artificial
  thickness changes the target set and must be accounted for in error claims.

Intersection construction:
  T_ij = C_i intersect R_j,
where C_i is a local convex outer envelope and R_j an existing convex certified
collision-free region. Each nonempty T_ij is convex and inherits R_j's collision
freedom, subject to the validity of that region's collision model/certification.
- Intersecting cannot create coverage that the original IRIS collection lacked.
- It can remove colliding SSM portions, which are not valid physical goals.
- SSM samples being collision-free does not certify their entire convex hull.
  A hull of points all in the SAME certified convex free region is contained
  in that region and therefore safe under the same collision model.
- Collision freedom does not automatically establish reliability 1.

GCS integration:
- Multiple target sets may be placed in a single graph and connected to a common
  zero-cost terminal sink; one need not invoke GCS once per local envelope.
- More targets can increase vertices, edges, solver variables, and runtime even
  when the top-level solve is invoked once.
- Graph construction must preserve the intended routes and not introduce
  uncharged teleportation or shortcut costs through target/sink modeling.
- Drake VPolytope represents the convex hull of points given as COLUMNS.
  Conceptually, for configurations of shape (N,3):
    target_set = VPolytope(configurations.T)
    target_vertex = gcs.AddVertex(target_set, "target_ssm_hull")
- HPolyhedron/halfspace representations may better match the existing region
  workflow, but this design choice has not been implemented or benchmarked.
- Official API references:
  https://drake.mit.edu/doxygen_cxx/classdrake_1_1geometry_1_1optimization_1_1_v_polytope.html
  https://drake.mit.edu/doxygen_cxx/classdrake_1_1geometry_1_1optimization_1_1_graph_of_convex_sets.html

Projection for goal selection and final replanning:
- Project to the actual continuous SSM, not just to the nearest sampled point,
  if the claimed endpoint is intended to solve the continuous task.
- Select a collision-free q_hat on the corresponding branch. At a regular smooth
  unconstrained closest point, p-q_hat is perpendicular to the SSM tangent.
  Constrained branch/region endpoints can instead satisfy boundary conditions;
  perpendicularity alone is not a sufficient test of a global closest point.
- A convenient restriction is that p and q_hat belong to the same convex free
  region R_j. This also supplies a safe hypothetical connector if needed for a
  feasibility or error argument; it is NOT the returned motion.
- Such a q_hat need not be the globally nearest SSM point. Projection may need to be
  restricted to the appropriate branch/free-region intersection.
- Re-run full GCS with the original start q0 and fixed q_hat. The final motion
  may use a completely different route from the first-stage solution.
- Later, the user explicitly requested a separate diagnostic comparison using
  the first-stage path plus the projection segment. The planner now always
  records this under projection_connection_baseline after projection succeeds,
  with actual region-weighted connector cost, path, and validation results.
  It adds no GCS solves and does not replace the final second-stage route.
  stage2_minus_projection_connection_cost reports the cost difference when
  that diagnostic path passes validation. It is not a global optimality gap.
- This removes the specific route penalty caused by directly stitching on a
  projection segment. It does not prove q_hat is the best goal on the entire SSM.
- Remaining limitations include approximate goal selection, finite region/chart
  coverage, path representation, and GCS relaxation/rounding gaps.
- Validate the final endpoint's FK and the complete path using the original
  robot geometry. A point inside the hull is not automatically a goal IK state.

9. OPTIONAL ERROR CERTIFICATES AND RELATED WORK

The user wants a practical epsilon-controlled approximation, not an expensive
search for an unknown optimal path. No prior knowledge of the true optimum is
required to run the two-stage algorithm. A strict certificate is optional.

For compatible costs and route models:
  L = exact optimal cost to the union of outer target envelopes.
  U = cost of the SECOND-stage feasible path ending at true SSM point q_hat.
  J_star = optimal cost to the true goal SSM in the stated planning model.

If every relevant true goal is covered by the outer target sets AND the relaxed
route model contains all corresponding admissible original routes, then:
  L <= J_star <= U.
Thus U-L bounds suboptimality of that feasible complete path.

For a theoretical comparison only, suppose an exact first-stage optimum ends
at p and a safe connector to q_hat has length at most delta. If the second-stage
route model can represent the first route plus that connector, and the second
stage is solved optimally, it can do no worse than this hypothetical stitched
route. For unit connector weight:
  U <= L + delta, and U - J_star <= delta.
For connector weight bounded above by w_max, use w_max*delta instead.
The algorithm need not actually construct or return the stitched route.

Important qualifications:
- Geometric distance to the SSM alone does not guarantee a safe connector.
  A same-free-region connector bound is stronger than a distance-only bound.
- Sample hulls that miss continuous SSM points do not justify the claimed lower
  bound for the full continuous target problem.
- If GCS uses relaxation and rounding, a rounded feasible route cost is NOT
  automatically L. Use a valid certified relaxation/solver lower bound, and
  report the gap to the complete feasible U. A solver/rounding gap adds to the
  envelope approximation error.
- Bounds are relative to the represented route model unless full free-space
  coverage and path representation have also been established.
- A fixed endpoint path ending exactly on the SSM can certify optimality only
  when its cost matches a valid lower bound for the same problem.
- Full pre-failure reliability-weighted costs need their actual weighting and
  connector costs included; do not transfer unit-weight length claims blindly.
- A small certified gap can be reported using available valid lower bounds;
  this does not require an epsilon sweep or knowledge of J_star. A loose gap is
  not itself evidence that the returned path is poor.

Novelty discussion after the first handoff version:
- GCS with convex goal sets and continuous endpoint choice is existing work:
  Shortest Paths in Graphs of Convex Sets:
  https://groups.csail.mit.edu/robotics-center/public_papers/Marcucci21.pdf
- A particularly relevant baseline is David von Wrangel and Russ Tedrake,
  Using Graphs of Convex Sets to Guide Nonconvex Trajectory Optimization (2024).
  It uses convex surrogates and nonlinear optimization, explicitly discusses
  task-space endpoint constraints, and jointly considers motion planning/IK:
  https://groups.csail.mit.edu/robotics-center/public_papers/Wrangel24.pdf
- Threshold-controlled approximate convex decomposition also predates this
  proposal. CoACD (2022) controls detail versus convex-component count with a
  distance-related threshold and considers both boundary and interior error.
  Its setting is 3D object geometry rather than goal SSM endpoint selection:
  https://arxiv.org/abs/2205.02961
  https://colin97.github.io/CoACD/
- Therefore a global epsilon parameter alone is not established novelty.
  Potential contribution: an effective adaptive SSM target representation plus
  two-stage goal selection/replanning, supported by runtime/quality comparisons
  and, if desired, approximation or convergence results.
- No exhaustive search established either that this exact two-stage combination
  already exists or that it is new. Do not claim a first-of-its-kind result.
